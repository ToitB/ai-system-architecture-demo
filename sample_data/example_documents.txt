# Sample Documents for AI System Architecture Demo

This file contains example documents you can use to test the API.
All examples are synthetic and generic.

## Example 2: Technical Documentation
The application architecture consists of three primary layers: presentation, business logic, and data access. 
The presentation layer handles user interactions through a web interface. 
The business logic layer processes requests and applies validation rules. 
The data access layer manages persistence operations using a relational database. 
Each layer maintains clear separation of concerns to enhance maintainability.

## Usage Examples

### Using curl:

# Analysis task
curl -X POST "http://localhost:8000/api/process" \
  -H "Content-Type: application/json" \
  -d '{"document_text": "The quarterly financial results exceeded expectations with a 15% increase in revenue.", "task_type": "analysis"}'

# Summarization task
curl -X POST "http://localhost:8000/api/process" \
  -H "Content-Type: application/json" \
  -d '{"document_text": "This ergonomic office chair features adjustable lumbar support, breathable mesh backing, and multi-directional armrests. The pneumatic height adjustment allows customization for users of varying heights.", "task_type": "summarization"}'

# Classification task
curl -X POST "http://localhost:8000/api/process" \
  -H "Content-Type: application/json" \
  -d '{"document_text": "This study examines the relationship between exercise frequency and cognitive performance in adults.", "task_type": "classification"}'

### Using Python requests:

import requests

url = "http://localhost:8000/api/process"

# Example request
response = requests.post(url, json={
    "document_text": "The quarterly financial results exceeded expectations.",
    "task_type": "analysis"
})

print(response.json())

### Using JavaScript fetch:

const response = await fetch('http://localhost:8000/api/process', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    document_text: 'The quarterly financial results exceeded expectations.',
    task_type: 'analysis'
  })
});

const result = await response.json();
console.log(result);
